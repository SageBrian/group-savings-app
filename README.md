# saving-app
<p id="description">This is an app that allows users to create groups add contributions and manage withdrawals by members by approval or rejection from the admin. This give a simplistic and interesting way to do contribution groups.</p>

  
  
<h2>🧐 Features</h2>

Here're some of the project's best features:

*   ability to add create a group
*   add members or join an existing group
*   make withdrawals
*   make withdrawals
*   approve and reject contributions

<h2>🛠️ Installation Steps:</h2>

<p>1. npm install for the frontend</p>

```
npm install 
```

<p>2. install backend dependancies</p>

```
pip install -r requirements.txt
```

  
  
<h2>💻 Built with</h2>

Technologies used in the project:

*   react vite for the frontend and flask for the backend and also postgress for the database
